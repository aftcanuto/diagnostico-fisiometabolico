# Modelos corporais de antropometria

Os modelos corporais masculino e feminino sao ilustracoes clinicas originais geradas para o MedFit em 2026-10-11 com OpenAI Image Generation. A galeria do Magnific indicada pelo usuario foi usada apenas como referencia conceitual de qualidade; nenhum arquivo da plataforma foi baixado, copiado ou redistribuido.

- Fontes preservadas: `resources/anthropometry/human-female-front-medfit.png` e `resources/anthropometry/human-male-front-medfit.png`
- Derivados otimizados: `human-female-front-clinical.png` e `human-male-front-clinical.png`
- Geracao reproduzivel: `node scripts/build-anthropometry-body-assets.mjs`

Cada figura combina superficie corporal e anatomia muscular em vista anterior, com cobertura clinica e fundo transparente. Os ativos sao ilustrativos e nao representam diagnostico.
